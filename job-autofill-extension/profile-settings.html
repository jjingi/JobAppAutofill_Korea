지원서 자동완성 설정

이력서와 포트폴리오를 분석해 프로필을 저장하고, 채용 사이트 질문에 맞춰 한국어 답변을 작성합니다.

현재 파일 미리보기로 열려 있어 실제 확장 프로그램 저장소가 아닌 브라우저 임시 저장소를 사용합니다. 실제 사용은 chrome://extensions에서 확장 프로그램 옵션 페이지로 열어 주세요.
기본 정보
학력

학교명, 전공, 재학기간, 졸업구분, 성적처럼 채용 사이트 학력란에 반복 입력되는 정보를 저장합니다.

경력

인턴, 직장경력, 동아리 운영진처럼 회사/조직 단위로 입력해야 하는 내용을 저장합니다.

프로젝트 / 자기소개
추가 정보

장애/보훈/병역 정보는 사용자가 직접 입력한 경우에만 자동완성에 사용합니다.

AI 자동완성

AI 사용 시 현재 페이지의 폼 문구와 저장된 프로필이 OpenAI API로 전송됩니다.
